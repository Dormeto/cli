# @dormeto/cli

The Dormeto command line. `dormeto estimate` estimates what Dormeto would save on an AWS organization.

```sh
npx @dormeto/cli estimate --help
npm install -g @dormeto/cli
```

This package is a small launcher: it runs the binary of the platform package npm installed for your machine
(`@dormeto/cli-<darwin|linux|win32>-<arm64|x64>`, an optional dependency). Do not install with `--omit=optional`.

Other ways to install, and the source: https://github.com/Dormeto/cli
